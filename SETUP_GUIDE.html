2
Create the READ flow in Power Automate
~8 minutes · done once · no admin access needed
1

Open Power Automate

Go to make.powerautomate.com in your browser. Sign in with your work Microsoft 365 account (the same account that has access to the SharePoint file).

💡 Power Automate is included in Microsoft 365 Business Basic, Standard, and Premium — no extra licence needed.
2

Create a new Instant cloud flow

Click + Create in the left sidebar → Instant cloud flow. Name it CloudOps READ. Under "Choose how to trigger this flow", scroll down and select Manually trigger a flow for now (you'll change it to HTTP in a moment). Click Create.

3

Change the trigger to HTTP Request

On the trigger card, click the three dots ⋯ → Delete. Then click + Add a trigger, search for When an HTTP request is received and select it.

On the trigger card:

  • Set Method to GET
  • Set Who can trigger the flow? to Anyone
⚠️ The HTTP POST URL only appears after you Save the flow for the first time. Save now and come back to copy it in step 11.
4

Add 8 "List rows" actions — one per Excel table

Click + New step. Search Excel Online (Business) → select List rows present in a table.

Fill in the first action:

  • Location: select your SharePoint site from the dropdown
  • Document Library: select the library where you uploaded the Excel
  • File: click the folder icon and pick CloudOps_Shift_Board.xlsx
  • Table: select tbl_ZD

Click the three dots ⋯ on this action → Rename → type Get_ZD.

Repeat this step 7 more times for each table, renaming each one as shown below:
Table nameRename action to
tbl_ZDGet_ZD
tbl_JiraGet_Jira
tbl_LimitedGet_Limited
tbl_ProvisioningGet_Prov
tbl_InformationGet_Info
tbl_ProjectGet_Project
tbl_RemoteHandsGet_RH
tbl_HandoverGet_Handover
5

Add the Response action

Click + New step. Search Request → select Response (from the Request connector).

Configure it:

  • Status Code: 200
  • Headers: click Add new item twice and add:
      Key Content-Type → Value application/json
      Key Access-Control-Allow-Origin → Value *
  • Body: click in the field → switch to Expression tab → paste the expression below → click OK
json(createObject(
  'zd',       body('Get_ZD')?['value'],
  'jira',     body('Get_Jira')?['value'],
  'limited',  body('Get_Limited')?['value'],
  'prov',     body('Get_Prov')?['value'],
  'info',     body('Get_Info')?['value'],
  'project',  body('Get_Project')?['value'],
  'rh',       body('Get_RH')?['value'],
  'handover', body('Get_Handover')?['value']
))
💡 Type this exactly as shown. The single quotes around the key names and around action names are important. If any action name differs, update it to match.
6

Save and copy the HTTP URL

Click Save (top right). Once saved, click on the trigger card ("When an HTTP request is received") to expand it. You'll see the HTTP POST URL — it looks like:

https://prod-xx.westeurope.logic.azure.com:443/workflows/abc123.../triggers/manual/paths/invoke?api-version=2016-06-01&sp=/triggers/manual/run&sv=1.0&sig=XXX

Click the copy icon next to the URL. Save it somewhere — you'll paste it into the dashboard next.

✓ Your READ flow is ready. Test it by pasting the URL into a browser tab — you should see a JSON response with your Excel data.
3
Create the WRITE flow in Power Automate Optional
~10 minutes · enables saving changes back to Excel automatically
1

Create another Instant cloud flow

Same as before — + Create → Instant cloud flow. Name it CloudOps WRITE. Use the HTTP trigger, Method = POST, Who can trigger = Anyone.

2

Set the Request Body JSON Schema

On the trigger, click "Use sample payload to generate schema". Paste this sample and click Done:

{"section":"zd","rows":[{"TicketID":"242800","Organization":"BNPP","Subject":"Test ticket","Status":"In progress","Notes":"Test"}]}
3

Add a Switch action

Click + New step → Control → Switch. In the "On" field, click in the box → Dynamic content → select section (from the trigger body).

4

Add cases for each section

Click Add Case for each of these values: zd, jira, limited, prov, info, project, rh, handover.

Inside each case, add two actions:

  • Excel → Delete a row — pick the matching table. Key Column = first column name (e.g. TicketID). Key Value = * to clear all.
  • Apply to each on expression triggerBody()?['rows'] → inside, add Excel → Add a row into a table → map each column to items('Apply_to_each')?['ColumnName']
⚠️ This replaces all rows in the table on each save. The dashboard sends the complete current state, not just changes.
5

Add Response action and save

After the Switch, add Request → Response. Status 200, Header Access-Control-Allow-Origin = *, Body = {"ok":true}. Save and copy the HTTP POST URL.

4
Connect the dashboard to Power Automate
~2 minutes · done once per device by each team member
1

Open CloudOps_Shift_Board.html

Double-click the HTML file to open it in your browser (Chrome or Edge recommended). You'll see a loading screen — that's expected.

2

Click Setup (top right corner)

Click the ⚙ Setup button in the top-right. The setup dialog opens with three tabs: READ flow, WRITE flow, Enter URLs.

3

Click "Enter URLs" tab and paste the flow URLs

Paste your READ flow HTTP POST URL into the first field. Paste your WRITE flow URL into the second (or leave it blank to use manual export only). Click Save and connect.

✓ The dashboard immediately calls the READ flow and loads all your Excel data. From now on it auto-loads every time the file is opened — no more clicks needed.
4

Share with your team

Send the CloudOps_Shift_Board.html file to each team member. They open it, click Setup once, paste the same two URLs, and they're connected. After that it's automatic for everyone.

💡 Tip: Save the READ and WRITE flow URLs in a shared Teams message or OneNote so team members can copy them easily.
5
Daily workflow for your team
What everyone does every shift

How it works day-to-day

  • 1 Open CloudOps_Shift_Board.html in your browser — data loads automatically from SharePoint
  • 2 Add new Zendesk or Jira tickets using the Add row at the bottom of each section
  • 3 Edit any cell directly by clicking on it — all cells are editable in place
  • 4 Change ticket statuses using the dropdown in the Status column
  • 5 Click Save to Excel — if WRITE flow is set up, changes save directly to SharePoint. Otherwise an Excel file downloads.
  • 6 At handover time, go to Handover notes → fill in Outgoing notes → hand over to next person
  • 7 Next shift person opens the file — previous handover appears automatically
  • 8 Dashboard always shows the latest data from SharePoint
